# Superpowers Skill Suite

Superpowers equips the AI coding agent with disciplined engineering methodologies.

## Core Capabilities Included:
- **`using-superpowers`**: Establishes rule enforcement and skill selection before answering or coding.
- **`brainstorming`**: Socratic creative and technical discovery before feature creation.
- **`writing-plans`**: Step-by-step implementation plans before touching code.
- **`executing-plans`**: Strict task-by-task execution discipline.
- **`test-driven-development`**: Red-Green-Refactor test cycle enforcement.
- **`systematic-debugging`**: 4-phase root cause discovery before proposing patches.
- **`requesting-code-review` & `receiving-code-review`**: Multi-agent adversarial code auditing.
- **`verification-before-completion`**: Verifying proof and running tests before declaring success.
- **`finishing-a-development-branch`**: Clean integration and merge validation.
- **`subagent-driven-development` & `dispatching-parallel-agents`**: Work delegation.
