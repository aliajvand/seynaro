# ارکستراسیون سوارم و پروتکل‌های اجماع بین چند ایجنت (multi-agent-swarm-orchestrator)

## خلاصه راهبردی (Executive Summary)
این اسکیل تخصصی چارچوب استانداردهای مهندسی و عملیاتی برای حوزه **سیستم‌های ایجنتی و مولتی‌ایجنتی (Agentic & Multi-Agent)** را تعیین می‌کند. نرخ بازدهی این اسکیل **98٪** است.

### قابلیت‌ها و ویژگی‌های کلیدی
معماری حافظه تخته سیاه اشتراکی (Blackboard Architecture)، مناظره و داوری همتا (Adversarial Peer Review)، جلوگیری از بن‌بست چرخه تصمیم‌گیری، واگذاری پله‌ای تسک‌ها.

### مزیت رقابتی نسبت به سایر اسکیل‌ها
همکاری هوشمندانه تیمی از چندین ایجنت متخصص (طراح، برنامه‌نویس، سکیوریتی و تستر) بدون هدررفت توکن و با رسیدن به بالاترین کیفیت تولید نرم‌افزار.

## دستورالعمل‌های الزامی (Directives & Execution Protocol)
1. **اصول استانداردسازی:** هرگونه پاسخ یا کد تولیدی تحت این اسکیل باید به طور کامل با معماری‌های رسمی سازمانی و اصول Clean Code مطابقت داشته باشد.
2. **پیشگیری از خطا:** اعتبارسنجی ورودی‌ها و خروجی‌ها پیش از اعمال نهایی الزامی است.
3. **مستندسازی و تست:** تمام کامپوننت‌ها باید به همراه توضیحات فنی، کامنت‌های ساختاری و نمونه‌های تست متناظر ارائه شوند.
4. **تمرکز بر نتیجه تجاری:** خروجی‌ها باید قابل استفاده مستقیم در پروداکشن باشند و بار شناختی کاربر را به حداقل برسانند.
